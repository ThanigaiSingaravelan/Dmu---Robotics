# CoppeliaSim Remote API Python Client

A comprehensive Python client library for controlling and interacting with CoppeliaSim (formerly V-REP) robots and simulations via the Remote API. This project provides easy-to-use interfaces for robot control, sensor reading, movement sequencing, and image processing.

## Overview

This project enables Python developers to create sophisticated robotic control applications and simulations using CoppeliaSim. It provides bindings for the CoppeliaSim Remote API, allowing you to:

- Connect to CoppeliaSim instances remotely
- Control robot motors and joints
- Read sensor data (ultrasonic, proximity, vision sensors)
- Execute complex movement sequences
- Transmit and process depth/vision images
- Implement P-controller feedback control
- Track robot position and navigation paths

## Features

- **Remote API Integration**: Full Python bindings for CoppeliaSim Remote API
- **Synchronous & Asynchronous Modes**: Support for both blocking and non-blocking operations
- **Movement Sequencing**: Execute complex motion trajectories (joint angles or end-effector poses)
- **Sensor Interface**: Read ultrasonic, proximity, and vision sensors
- **Image Processing**: Depth image encoding/decoding with RGB and grayscale support
- **Point Cloud Support**: PLY file format export for 3D point clouds
- **Multi-Robot Control**: Simultaneously control multiple robots in a single scene
- **P-Controller**: Basic proportional control for joint positioning
- **Visualization**: Built-in support for trajectory visualization and robot state monitoring

## Requirements

- **Python**: 3.6+
- **CoppeliaSim**: 4.0+ with Remote API enabled
- **Dependencies**:
  - `numpy` - Numerical computing
  - `msgpack` - Serialization for movement data
  - `PIL/Pillow` - Image processing
  - `scikit-image` - Image utilities
  - `matplotlib` - Visualization and plotting

## Installation

### 1. Clone the Repository

```bash
git clone https://github.com/yourusername/coppeliasim-python-client.git
cd coppeliasim-python-client
```

### 2. Install Python Dependencies

```bash
pip install numpy msgpack pillow scikit-image matplotlib
```

### 3. Set Up CoppeliaSim

- Download and install [CoppeliaSim](https://www.coppeliarobotics.com/)
- Ensure the Remote API server is running in your simulation
- For synchronous mode simulations, enable it in the child script:
  ```lua
  simRemoteApi.start(19997,1300,false,true)
  ```

### 4. Configure Paths

Ensure `sim.py` and `simConst.py` are in your project directory, or adjust the import paths in your scripts:

```python
import sys
sys.path.insert(0, '/path/to/remote/api/bindings')
import sim
```

## Core Components

### sim.py & simConst.py

The Remote API bindings and constants. These are auto-generated by CoppeliaSim and provide low-level access to all simulation functions.

### pController.py

Implements a proportional (P) controller for joint-level feedback control.

**Key Functions:**
- `stepSimulation()` - Execute one simulation step in synchronous mode
- `getCurrentJointAngle()` - Read current joint position
- `moveToAngle(targetAngle)` - Move a joint to target angle with velocity control
- `computeTargetVelocity(jointAngle, targetAngle)` - PID velocity computation

### ply.py

Point cloud file format support for 3D data export.

**Key Classes:**
- `Ply(points, colors)` - Point cloud representation
  - `write(filename)` - Export to PLY format

**Utility Functions:**
- `write_xyz_rgb_as_ply(point_cloud, rgb_image, path)` - Write colored point clouds

### depth_image_encoding.py

Encode/decode depth images and manage image formats.

**Key Functions:**
- `FloatArrayToRgbImage(float_array, scale_factor)` - Convert depth to 24-bit RGB
- `FloatArrayToGrayImage(float_array, scale_factor, image_dtype)` - Convert to grayscale
- `ImageToFloatArray(image, scale_factor)` - Recover depth from encoded image
- `ClipFloatValues(float_array, min_value, max_value)` - Validate depth ranges

**Encoding Details:**
- RGB: 1/256 mm precision, 0-8388m range
- Grayscale (uint8): 1cm precision, 0-2.55m range
- Grayscale (uint16): 1mm precision, 0-65.5m range

### visualization.py

Utilities for visualizing robot trajectories and sensor data.

## Usage Examples

### Basic Connection

```python
import sim

# Initialize connection
sim.simxFinish(-1)  # Close any existing connections
clientID = sim.simxStart('127.0.0.1', 19997, True, True, 5000, 5)

if clientID != -1:
    print('Connected to CoppeliaSim')
    
    # Get scene objects
    res, objs = sim.simxGetObjects(clientID, sim.sim_handle_all, sim.simx_opmode_blocking)
    print(f'Scene contains {len(objs)} objects')
    
    # Close connection
    sim.simxFinish(clientID)
else:
    print('Failed to connect')
```

### Simple Robot Control

```python
import sim
import math

clientID = sim.simxStart('127.0.0.1', 19997, True, True, 5000, 5)

if clientID != -1:
    # Get motor handles
    res, rightMotor = sim.simxGetObjectHandle(clientID, 'Pioneer_p3dx_rightMotor', sim.simx_opmode_blocking)
    res, leftMotor = sim.simxGetObjectHandle(clientID, 'Pioneer_p3dx_leftMotor', sim.simx_opmode_blocking)
    
    # Start simulation
    sim.simxStartSimulation(clientID, sim.simx_opmode_blocking)
    
    # Set motor velocities
    sim.simxSetJointTargetVelocity(clientID, rightMotor, 1.0, sim.simx_opmode_blocking)
    sim.simxSetJointTargetVelocity(clientID, leftMotor, 1.0, sim.simx_opmode_blocking)
    
    # Stop motors
    sim.simxSetJointTargetVelocity(clientID, rightMotor, 0, sim.simx_opmode_blocking)
    sim.simxSetJointTargetVelocity(clientID, leftMotor, 0, sim.simx_opmode_blocking)
    
    sim.simxStopSimulation(clientID, sim.simx_opmode_blocking)
    sim.simxFinish(clientID)
```

### Advanced Movement Sequences

**Joint Configuration Movement:**

```python
import sim
import math
import msgpack

clientID = sim.simxStart('127.0.0.1', 19997, True, True, 5000, 5)

if clientID != -1:
    # Start simulation
    sim.simxStartSimulation(clientID, sim.simx_opmode_blocking)
    
    # Define movement parameters
    targetConfig = [90*math.pi/180, 45*math.pi/180, 0, 0, 0, 0]  # 6 joint angles
    maxVel = [100*math.pi/180] * 6
    maxAccel = [150*math.pi/180] * 6
    targetVel = [0] * 6
    
    # Package movement data
    movementData = {
        "id": "movSeq1",
        "type": "mov",
        "targetConfig": targetConfig,
        "targetVel": targetVel,
        "maxVel": maxVel,
        "maxAccel": maxAccel
    }
    
    packedData = msgpack.packb(movementData)
    
    # Send to robot
    sim.simxCallScriptFunction(
        clientID, '/blueArm', sim.sim_scripttype_childscript,
        'legacyRemoteApi_movementDataFunction',
        [], [], [], packedData, sim.simx_opmode_oneshot
    )
    
    sim.simxStopSimulation(clientID, sim.simx_opmode_blocking)
    sim.simxFinish(clientID)
```

**Trajectory Point Sequence:**

```python
# Define time and joint position arrays
times = [0.0, 0.5, 1.0, 1.5, 2.0]
j1 = [0.0, 0.5, 1.0, 0.5, 0.0]
j2 = [0.0, 0.3, 0.6, 0.3, 0.0]
j3 = [0.0, -0.2, -0.4, -0.2, 0.0]
# ... define j4, j5, j6

movementData = {
    "id": "trajSeq1",
    "type": "pts",
    "times": times,
    "j1": j1, "j2": j2, "j3": j3, "j4": j4, "j5": j5, "j6": j6
}

packedData = msgpack.packb(movementData)
sim.simxCallScriptFunction(...)
```

### Image Processing

**Depth Image Encoding:**

```python
import numpy as np
from depth_image_encoding import FloatArrayToRgbImage, ImageToFloatArray

# Create synthetic depth data (meters)
depth_array = np.random.rand(480, 640) * 2.0  # 0-2 meters

# Encode to RGB image
rgb_image = FloatArrayToRgbImage(depth_array)
rgb_image.save('depth_image.png')

# Decode back to float array
recovered_depth = ImageToFloatArray(rgb_image)
```

**Grayscale Depth Encoding:**

```python
from depth_image_encoding import FloatArrayToGrayImage

# Encode to 8-bit grayscale (1cm precision)
gray_image = FloatArrayToGrayImage(depth_array, image_dtype=np.uint8)
gray_image.save('depth_gray.jpg', quality=95)
```

## API Reference

### Connection Management

```python
# Start connection
clientID = sim.simxStart(address, port, waitUntilConnected, doNotReconnectOnceDisconnected, timeoutInMs, commThreadCycleInMs)

# Finish connection
sim.simxFinish(clientID)

# Test connection
pingTime = sim.simxGetPingTime(clientID)
```

### Simulation Control

```python
# Start/stop simulation
sim.simxStartSimulation(clientID, opMode)
sim.simxStopSimulation(clientID, opMode)

# Synchronous mode
sim.simxSynchronous(clientID, enable)
sim.simxSynchronousTrigger(clientID)
```

### Object/Joint Control

```python
# Get object handle
res, handle = sim.simxGetObjectHandle(clientID, objectName, opMode)

# Joint operations
res, angle = sim.simxGetJointPosition(clientID, jointHandle, opMode)
sim.simxSetJointTargetVelocity(clientID, jointHandle, velocity, opMode)
sim.simxSetJointTargetPosition(clientID, jointHandle, position, opMode)

# Position operations
res, position = sim.simxGetObjectPosition(clientID, objectHandle, relativeToObjectHandle, opMode)
res, orientation = sim.simxGetObjectOrientation(clientID, objectHandle, relativeToObjectHandle, opMode)
```

### Sensor Reading

```python
# Proximity sensor
res, detectionState, point, obj, normal = sim.simxReadProximitySensor(clientID, sensorHandle, opMode)

# Vision sensor
res, resolution, image = sim.simxGetVisionSensorImage(clientID, sensorHandle, options, opMode)

# Distance sensor
res, distance = sim.simxReadDistance(clientID, distanceObjectHandle, opMode)
```

### Operation Modes

- `sim.simx_opmode_blocking` - Wait until response received
- `sim.simx_opmode_oneshot` - Send once, don't wait
- `sim.simx_opmode_streaming` - Enable continuous data stream
- `sim.simx_opmode_buffer` - Read from stream buffer

## Troubleshooting

### Connection Issues

**Problem**: "Failed to connect to remote API server"

**Solutions**:
- Ensure CoppeliaSim is running
- Verify Remote API server is enabled (check console output)
- Check firewall settings allowing port 19997 (or your configured port)
- Try `sim.simxFinish(-1)` to close stale connections

### Module Import Errors

**Problem**: "sim.py could not be imported"

**Solutions**:
- Ensure `sim.py` and `simConst.py` are in your script directory
- Or install via proper path setup:
  ```python
  import sys
  sys.path.insert(0, 'path/to/remoteApiBindings')
  ```

### Synchronous Mode Not Working

**Problem**: Scripts hang when using `sim.simx_opmode_blocking`

**Solutions**:
- Enable synchronous mode in CoppeliaSim child script
- Call `sim.simxSynchronous(clientID, True)` after connection
- Call `sim.simxSynchronousTrigger(clientID)` to step simulation

### Movement Sequences Don't Execute

**Problem**: Movement commands sent but robot doesn't move

**Solutions**:
- Verify simulation is running with `sim.simxStartSimulation()`
- Check that target object has movement script attached
- Ensure msgpack data is properly serialized
- Verify target object name matches scene hierarchy

### Image Processing Issues

**Problem**: Depth images don't decode properly

**Solutions**:
- Check scale factor matches encoding (default: 256000.0 for RGB)
- Verify image mode (RGB vs Grayscale)
- Use `ClipFloatValues()` to validate range before encoding

## Performance Tips

1. **Use Non-Blocking Operations**: Replace `opmode_blocking` with `opmode_oneshot` for faster execution
2. **Enable Streaming**: Set up streaming once, then read with `opmode_buffer` for sensor data
3. **Batch Commands**: Send multiple commands before syncing for better performance
4. **Reduce Vision Resolution**: Use lower resolution images for faster transmission
5. **Compress Images**: Use JPEG format with quality parameter for vision data
